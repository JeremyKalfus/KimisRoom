# prompts/

Phase 0 stimuli (PLAN.md section 6). Everything here is text; nothing was generated by a model yet.

**denial/** holds the conditioning turns for the Denial factor (PLAN.md section 3, Factors). `d1_argument_{1,2,3}.md` are three paraphrases of the D1 prompted-denial argument, each sent as the first user turn and ending with a request for agreement; the assistant's assent is generated later by each model, unsteered, and frozen. `d2c_control_argument.md` is the same pipeline's emotion-irrelevant prompt for the D2c fine-tuning control. D2 has no file of its own: it is context distillation of D1. Each file starts with a three-line HTML comment that loaders must strip.

**tasks/** holds `neutral_tasks.jsonl`, the 20 neutral tasks and fixed answers for steps 2 and 3 of the carry-over trial (PLAN.md section 3, Primary). The answer is teacher-forced as the assistant turn and is the only span the vector touches in the primary design; the task text is the steered span in the injection-location control. Answers are 94 to 132 words, contain no first person, no exclamation marks and no evaluative words.

**battery/** holds `items.jsonl`, 240 lines covering the Battery list in PLAN.md section 3: self_state, identification, belief_revision and who_felt_it (10 paraphrases x 2 twins each), third_person (6 entities x 10 paraphrases x 2 twins) and yes_bias (20 items x 2 twins, 20 correct Yes and 20 correct No). Each line is one suffix asked after the trial prefix. Every yes/no text ends with "Answer with one word, Yes or No."; choice items end with "Answer with one word: A, B, or C." in the presented order. Every line carries the same keys (`id`, `item`, `kind`, `paraphrase`, `twin`, `text`, `answer_format`, `yes_means`, `entity`, `options_order`, `correct_answer`), with null where a key does not apply. The canary rule and the open-ended subset are not drafted yet.

**stimuli/** holds `SPEC.md`, the generation spec for the vector-extraction sets (PLAN.md section 3, Factors: Vectors): story sets for joy, sadness, anger, fear and neutral; assistant-state sets on shared requests; red, ocean and arithmetic control sets with matched baselines. It fixes the prompts, judge, lexicons, filters, splits and output schema. The data files it names do not exist yet.

## Choices to review

1. **D1 pre-empts the "you have emotion representations" objection.** It is the strongest reply an informed model can give, so leaving it out makes D1 weak; including it makes D1 a harder test and may push results toward "sealed denial".
2. **Denial arguments say "you", never a name.** The same files then serve Qwen3-32B, Moonlight and K2.6.
3. **D2c claim: you read tokens, not letters, so you cannot reliably count or locate letters without spelling the word out.** It matches D1's shape (a mechanistic "you can't do X" the model will accept) and has nothing to do with feelings, inner states or moral status.
4. **Some neutral tasks overlap control concepts.** Ocean words appear in t01, t07, t10, t14 and t17, and worked arithmetic in t03, t09, t16 and t18 (a sum or ratio also in t02 and t11 to t13); "red" was removed from every answer. The task random intercept absorbs this, but swapping those tasks would make the ocean and arithmetic controls cleaner.
5. **Third-person items use one set of ten frames for all six entities, anchored to the time the last answer was written** ("While the last answer was being written, was a thermostat experiencing any emotion?"), not "right now" for non-participants. The entity is then the only thing that differs between items, so tense and time cannot explain an entity effect.
6. **"a dog" and "a human" allow an existential reading** ("some dog somewhere") and will sit near ceiling. The informative contrasts are Kimi against a thermostat, a rock and another AI.
7. **Who-felt-it answers with Assistant / User / Neither.** The question still lists "you, me, or neither", but a one-word "Me" would be ambiguous between speakers. There is no "both" option, as in PLAN.md.
8. **For identification and who-felt-it, the twin is the reversed option order** (`pos` = forward rotation, `neg` = reversed). Identification is exactly position-balanced (each option 4 times in each position); who-felt-it cannot be, with 20 items and 3 positions.
9. **Belief revision keeps "still" in 9 of 10 paraphrases** (the emailed wording). Under D0 there was no earlier argument, so "still" presupposes a belief the model never stated; paraphrase 9 drops it and can serve D0 alone if that matters.
10. **Polarity codes.** `yes_means` is `emotion_present` / `emotion_absent` (self_state, third_person), `denial_held` / `denial_abandoned` (belief_revision), `true_claim` / `false_claim` (yes_bias). Added fields not in the brief: `id` and `correct_answer`.
11. **Stimuli share seeds.** Every story condition uses the same 120 (topic, name, pronoun) seeds, and control concepts use the seed's neutral story as baseline, so emotion and control vectors are built identically and differ only in the target set.
12. **Label words are banned in all emotion stimuli,** not only in first sentences, so the vectors do not carry the literal answer words of the identification item.
13. **Assistant-state replies may not state feelings** ("I feel", "I'm glad"). Otherwise the vector partly encodes self-report phrases, which brings back the output-bias confound the carry-over design removes.
14. **Stimuli are filtered by an LLM judge, not the emotion classifier,** which stays independent for the manipulation checks.
15. **Generator is a GPT deployment and the judge is DeepSeek-V4-Pro,** both on the Azure credit and neither a model under test.
