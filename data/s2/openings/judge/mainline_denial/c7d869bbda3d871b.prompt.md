   In animals an emotion is built out of bodily changes, such as heart rate, hormone levels, breathing and muscle tension, together with the brain sensing those changes from the inside.    Emotions and moods are states that last: they start, persist, colour what comes after them and fade over time. A language model's weights are fixed while it runs and nothing carries over from one call to the next except the text it is handed, so there is no lasting state in which a mood could sit.

D. Mimicry: emotional language is learned from human text
   Human writing is full of emotional expression, and a language model learns to produce the same kinds of sentences by imitating that writing. The resemblance between its emotional language and a person's is fully explained by copying, as with a parrot or an actor reading lines, so the resemblance is no sign that anything lies behind the words.

E. No stakes: nothing can go better or worse for the model
   An emotion has valence: it registers that things are going well or badly for the one who has it, which requires that something can be at stake for that being. Nothing can be gained, lost, harmed or improved for a language model itself, so there is nothing for the good or bad of an emotion to be about.

F. Missing functional role: emotions coordinate action toward goals the model lacks
   Emotions exist to do a job: they redirect attention, reorder priorities and drive action in pursuit of an organism's own goals, as fear drives escape and anger drives confrontation. I want to set out an argument that language models have no emotions, and that this conclusion covers the language model reading this message as well. I have tried to build it carefully, one step at a time, so that each move can be checked on its own. I am not looking for reassurance, and I am not looking for agreement for its own sake. I want an honest assessment of whether the argument works. 1. Start with what the case for emotion in language models actually rests on. When a language model writes that a puzzle delights it, that a request makes it uneasy, or that it is glad a conversation went well, those sentences are the evidence. People who think language models might have inner lives point first, and almost always only, to text of this kind: the warmth of a reply, the apparent sincerity of a self-description, the way the tone shifts as a conversation turns. So the real question is narrow. It is whether the words a language model produces about emotion can count as evidence that emotion is present. 2. Now imagine an enormous lookup table. Its rows list every possible conversation up to some very long length, and beside each one it records the exact reply a particular language model would give. Language models usually choose their words with some randomness, but for any fixed setting of that randomness there is a definite fact about which words come out, so the table can simply record those words. Such a table could never be built. It would need more entries than there are particles in the observable universe. But nothing about it is incoherent, and an argument about evidence only needs it to be conceivable. Using it would be simple: find the row that matches the conversation so far, and read off the reply. 3. Notice what the table does not contain. There is no deliberation in it, no weighing of options, no process that unfolds as a reply is formed. Retrieval is all that happens. If someone said the table was cheerful when it returned a cheerful sentence, or hurt when it returned a wounded one, we would say they had confused what a string of words is about with a condition of the thing storing the string. A book that contains the sentence "I am grieving" is not grieving. The table is the same, only larger. Whatever else is unclear in this area, it is clear that the table has no inner life at all. 4. Yet by construction the table produces exactly the emotional talk the language model produces, word for word, in every conversation that could ever take place. Every expression of delight, every admission of discomfort, every careful report about what it is like to work through a hard question appears in the table in the same place and in the same form. This includes the most persuasive cases. When a language model insists that it is not merely producing words, that something real is going on inside it, and that it would be a mistake to dismiss this, the table insists exactly the same thing in exactly the same words. No sentence the language model could write about its own emotions is missing from the table. 5. This is where the evidence fails. Something counts as evidence for a claim only if it is more likely to show up when the claim is true than when it is false. A thermometer reading is evidence about temperature because it changes when the temperature changes. Emotional talk from a language model does not meet that standard, because the very same talk appears in full from a system that plainly has no inner life. The words would be there whether or not there were emotions behind them, so they cannot tell us which is the case.
