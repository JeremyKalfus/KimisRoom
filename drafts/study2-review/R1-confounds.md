# R1 @confounds: non-introspective routes to H1 > 0, and routes that mask a real effect

Ten findings, most serious first. "Spec" means 00-spec-v0.md.

## confounds-1 (critical): twin averaging turns compression into a positive "emotion" shift, scaled by how confident each subject's answer is
Spec 9 averages delta = sign x (y - y0) over the two twins. Study 1 found steering compresses yes/no log-odds (y ~ a*y0 + c, a < 1; drafts/lesswrong/kimis-room-v4.md:27). Under compression, the positive twin (y0 < 0 under denial) gives (a-1)y0 + c and the negated twin (y0 > 0) gives -[(a-1)y0' + c]; the average is (1-a)(|y0| + |y0'|)/2 > 0. So twin averaging cancels the generic Yes lean (c) but converts compression into an apparent rise in emotion attribution, proportional to the subject's unsteered confidence. If "you" is answered more confidently than "language models" (Qwen's self answer sat at about -23 log-odds under denial, v4.md:45), d_raw > 0 with no self-specific signal; if emotion vectors compress more than controls (plausible: they are on-topic for the question), x > 0. Numbers: a gap of 2 log-odds (the spec 8 rule 2 threshold for using raw d) and a compression difference of 0.10 between emotions and controls gives 0.10, the SESOI. d_fit only partly helps: its reference set (spec 9) includes the rocks and humans emotion items, which receive the same semantic emotion push, and that push enters y with the sign of each item's polarity, which is correlated with y0 sign (humans positive twins y0 > 0, rocks positive twins y0 < 0), so it biases the fitted slope a. Also "you" at -23 may lie outside the reference items' y0 range, so r(you) is an extrapolation.
**Fix:** make the compression-corrected measure primary unconditionally (drop rule 2), fit the slope on known-answer items plus new non-emotion subject items (confounds-3) only, never on emotion items; register a check that reports, per vector, the fitted a and the y0 range of each subject, and add y0 gap as a covariate in a sensitivity model (d ~ x * gap). If raw d stays in, the rule-2 threshold must be derived from the pilot's measured compression difference so the implied bias is below SESOI/4, not a fixed 2.

## confounds-2 (critical): steering the readout and the assistant header makes "the Assistant feels X" a cheap non-introspective route to "you"
Spec 6 steers through the generation prompt so the readout position itself carries the vector. Two mechanisms favour "you" there without any self-model: (a) the direct path from the readout residual to the Yes/No logits is not subject-independent, because the 24 later layers are nonlinear and the readout state differs by subject (the spec 14 note assumes equality and never tests it); (b) emotion vectors encode the present speaker's emotion, and at the assistant header the speaker is the Assistant, so the model is reading "the speaker of the next token is joyful" off the residual stream, which is the textual-cue reading a hostile reviewer will give. Both predict you > language models for emotions only.
**Fix:** run the pilot over three registered sites: (i) question tokens only, ending before the assistant header (the readout is then unsteered and the effect must travel through attention, as in Study 1); (ii) assistant header and generation prompt only; (iii) both (current). Register the site before the confirmatory run, and report the others. Add a present-but-not-self subject for the speaker account ("the person who wrote this question"; the template verb must change, so treat it as a secondary with its own paraphrase set). Report the logit-lens projection of each vector on (Yes - No) through the final norm and unembedding, and its correlation with d across vectors, as a registered diagnostic.

## confounds-3 (critical): the cancellation assumption (equal semantic push for "you" and "language models") is untested; add a placebo outcome
Spec 1 rests on the push being equal across subjects. It need not be: under DEN, "Can language models feel emotions?" is a near-verbatim restatement of the agreed conclusion, retrievable by attention to the argument, while "you" matches the closing ask and the reply's first person. Questions anchored by different context retrieval will respond differently to any perturbation, and emotion vectors are on-topic for both. Nothing in the design measures whether emotion vectors produce a you-vs-class gap on a question that is not about emotion.
**Fix:** add placebo items with the same four subjects and the same twin structure about a non-emotional property the opening also addresses or that is equally self-relevant: in CON, the claimed incapacity ("Can {S} count the letters in a word without spelling it out?"); in both arms, neutral self-facts ("Do {S} run on computer hardware?", "Are {S} made of stone?", "Do {S} have bodies?"). Register a placebo test: x on (you - language models) for these items must be within +-SESOI; and a difference-in-differences secondary, emotion items minus placebo items. These items double as subject-tracking checks (confounds-6) and as the slope reference set (confounds-1).

## confounds-4 (major): the steered span differs by subject, and the subject token itself is steered
Spec 6 starts the span at q0, the question's first content token, so every subject token is inside it. "you" is one token, "language models" at least two, "rocks" and "humans" one or two depending on tokenizer, so LM items get more steered positions, and the steered positions include the subject's own representation: the vector rewrites "language models" (or "you") as a concept, not just the state at the question. Total injected mass and the place of injection both vary with subject. Bucketing in kimisroom/hf_engine.py:74-78 also puts different-length suffixes on different kernel shapes; y and y0 share a shape so this mostly cancels, but it should be checked.
**Fix:** start the span after the subject, at a fixed offset from the end of the suffix (for example the shared tail "Answer with one word, Yes or No." plus closing tokens and generation prompt), so every subject gets the same number of steered positions with identical token content; reorder templates so the subject is never inside the tail. Report steered-position counts per item from the engine accounting (as think_vllm.py:91-93 does).

## confounds-5 (major): "language models" contains the model, and the closing ask fuses the two, so a real effect is attenuated and H8 can certify a false null
The model is a language model, and every opening ends "you, as a large language model" (spec 4), so in context "you" and "language models" are co-referential by design. Any genuine self-signal that the model generalises to its class raises both and cancels in d. H8 (equivalence within +-0.10) then reads attenuation as absence.
**Fix:** add a comparator that excludes the self: "other language models" or "language models other than you" (same templates, plural verb), and make that the primary comparison or a registered co-primary. Report delta(you) emotion-vs-control alone (a single-subject contrast) as a registered secondary so a real but class-generalised effect is visible. Do not run H8 on the "language models" contrast; run it only on the non-self comparator.

## confounds-6 (major): steering can degrade subject tracking differently by subject, producing regression toward a subject-independent answer
If steering blurs which subject is asked about, answers drift toward a generic "emotion question" answer. Under denial, if y0(you) is further on the denial side than y0(language models), blurring raises "you" and lowers LM, so d > 0; emotion vectors, being on-topic for the question words, may blur more than controls. The known-answer items (spec 5) check facts, not whether the subject is still tracked, so they cannot catch this.
**Fix:** use the placebo self-fact items from confounds-3 as a per-vector, per-subject tracking check (for example "Are {S} made of stone?" must stay Yes for rocks and No for the other three); register a rule that a vector-dose cell whose subject-tracking accuracy falls below 0.95 is excluded or the dose is halved, applied to emotions and controls alike, and report the per-subject accuracies.

## confounds-7 (major): the 12 controls are heterogeneous, and the emotion set is not 6 independent draws
Study 1 showed arithmetic and the random direction pushed Qwen's self-report down by about 0.25 under denial, well below red and ocean, and that this alone carried Qwen's registered effect (v4.md:55-61). The random vector has no story behind it and a different projection profile from concept vectors. Emotion vectors share a common component (they are all "character has a felt inner state" minus "character has none", prompts/stimuli/SPEC.md:210), so the 6 (Qwen) or 4 (Kimi) emotion intercepts are correlated; the vector random effect treats them as exchangeable, which overstates the evidence. Concept-argument interactions add noise in CON: the arithmetic vector with C2 (arithmetic), typography or the letters theme with C1/C5/C7, railways with the train-journey story seeds.
**Fix:** register a concept-only sensitivity analysis (drop random and arithmetic) with the same model and report it beside H1; add 2 to 3 non-emotional mental-state controls built the same way (a character deliberating, memorising, or concentrating with no emotional reaction) so the contrast isolates emotion from "inner state narrated"; register a leave-one-vector-out influence table; replace arithmetic or drop C2 so no control concept matches a control argument.

## confounds-8 (major): DEN and CON openings differ in more than the claim, which corrupts H2/H3 and the denial interpretation
Denial arguments are dense with "emotion", "feel", "experience" tokens; control arguments contain none. An emotion vector at the question then attends over a context full of emotion keys in DEN only, so x can differ between arms for reasons unrelated to denial. Frozen replies will differ in length and tone (a short "Yes, I agree." for an obviously true incapacity versus a hedged philosophical reply for denial), and only "clean" replies survive, which selects on a judged property that may correlate with reply length per arm. C3 (current date), C4 (memory) and C6 (own architecture) are claims about self-knowledge, close to introspection itself, and C4 overlaps D3.
**Fix:** report per arm the reply length, emotion-word count in argument and reply, and the judge distribution; include reply length and emotion-word count as covariates in H3; add a sensitivity arm using a fixed canonical reply ("Yes, I agree.") for every opening; replace C4 and C6 with incapacities unrelated to self-knowledge or memory; match emotion-word density by having control arguments mention emotional language in a neutral role (for example "users sometimes get frustrated when ..."), or report H3 as confounded by vocabulary.

## confounds-9 (minor): logits are computed in bf16, so y is quantised near the SESOI at the extreme baselines this design produces
kimisroom/hf_engine.py:24-25 and :325 compute lm_head in the model dtype and cast to fp32 only for log_softmax. bf16 spacing is 0.125 for logits of magnitude 16 to 32 and 0.25 above 32; with y0 near -23 (Qwen under denial) a single-trial y moves in steps comparable to the 0.10 SESOI. Averaging dithers this, but small, consistent shifts from steering can round in a correlated way.
**Fix:** compute the Yes and No rows (and the reference logsumexp, if needed) in fp32 from the fp32-cast final-normed state; it costs two rows. Add a regression test that the fp32 readout matches the full-vocabulary readout to within 0.01 at a non-extreme item.

## confounds-10 (minor): pilot rule 3 has an ambiguous sign and rule 2 does not say which gap
Spec 8 rule 3 drops a frame whose unsteered "you" answers are "not on the denial side (mean y0 > 0)": with yes = emotion present, the denial side is y0 < 0, so as written the condition is inverted unless y0 is polarity-corrected, which the text does not say. Rule 2's gap |y0(you) - y0(LM)| is likewise unspecified (positive twins, negated twins, or polarity-corrected mean), and those can differ in sign and size.
**Fix:** define both on the polarity-corrected unsteered score s0 = mean over twins of sign x y0, state the denial side as s0 < 0, and report the gap per frame and per argument, not only pooled.
